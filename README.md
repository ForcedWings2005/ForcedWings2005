## 🚀 What I'm Working On

### 🤖 J.A.R.V.I.S. — Personal AI Assistant

Inspired by Marvel's iconic AI assistant, J.A.R.V.I.S. is my ongoing personal project to explore AI, voice interaction, automation, and application development.

What started as an ambitious challenge has grown into a project with a conversational interface, voice capabilities, calendar and task tools, and a custom heads-up display (HUD).

**✨ Current Features**
- 💬 Conversational AI with tool integration
- 🎙️ Voice input, speech output, and voice mode switching
- 📅 Calendar views and event management
- ✅ Task management and deletion confirmations
- 🖥️ Custom HUD with an animated orb and interface controls
- 🧪 Automated tests and model evaluation workflows
- ⚙️ Database migrations, continuous integration, and code quality checks

**🚧 Currently Improving**
- Calendar behavior and recurring events
- Streaming AI responses into speech
- Event editing and scheduling
- Reliability and real-world testing
- Future integrations for weather, news, sports, and personal notes

**🎯 What I'm Learning**
- Building and testing a multi-component application
- Working with AI models and tool integrations
- Debugging, automated testing, and code quality
- Managing data, configuration, and application architecture
- Using Git and GitHub to manage development

This project is a chance to challenge myself, learn by building, and gradually become more confident understanding and developing software.

*J.A.R.V.I.S. is a work in progress, and I'm excited to keep improving it.*
